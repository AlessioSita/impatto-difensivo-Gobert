This code aims to evaluate the impact of an NBA player in a playoff series, specifically Rudy Gobert in the 2023/24 Denver–Minnesota series, which ended with Minnesota winning Game 7. A logistic regression model is first developed to estimate the probability that a shot comes from the midrange area. The explanatory variables considered include seconds since the start of the game, home or away status, and Rudy Gobert’s presence on the court.
Subsequently, a Poisson model is estimated on points scored per shot in order to assess whether the potential changes in shot selection had an impact on shot quality.
